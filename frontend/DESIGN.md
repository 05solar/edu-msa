# DESIGN.md · 프론트엔드 디자인 원칙

## 0. 필수 규칙 — 이모지/이모티콘 사용 금지

- **어떤 화면·컴포넌트·문자열에도 이모지(이모티콘)를 넣지 않는다.** (필수)
- 아이콘이 필요하면 `src/icons/Icon.tsx`의 **인라인 SVG 아이콘 세트**만 사용한다.
- 데이터에도 이모지를 저장하지 않는다. 분류/기능/제공방식의 아이콘은 SVG 키
  (예: `doc`, `auto`, `download`)로 표현한다.
- 코드 리뷰 시 이모지가 발견되면 머지하지 않는다.

## 0-1. 필수 규칙 — 알림/토스트에 좌측 색상 바(side marker) 금지

- **토스트·알림·경고 등 "알림창" 성격의 요소에 좌측 색상 바(예: `border-left: Npx solid ...`,
  `::before` 세로 바 등 side marker)를 절대 넣지 않는다.** (필수)
- 상태(성공/경고/정보) 구분은 **아이콘 + 텍스트**로만 표현한다(색만으로 구분하지 않는다).
- 과거 `.toast.ok/.warn/.info` 의 `border-left` 마커는 제거됨. 재도입 금지.
- 코드 리뷰 시 알림/토스트류에 side marker 가 발견되면 머지하지 않는다.

## 1. 디자인 출처

시각 디자인은 PoC 원본(`edu_poc_v2.html`)을 그대로 따른다. 색·간격·타이포·컴포넌트
형태를 유지하되, 원본의 이모지 아이콘만 SVG로 대체한다.

## 1-1. 테마 · 폰트 · 배율

- **폰트**: Pretendard (`src/styles/fonts.css`, 100~900 웨이트).
- **라이트/다크 테마**: `:root[data-theme="dark"]`가 토큰을 재정의한다. 상단바 토글로
  전환하며 `localStorage`에 저장. 표면색은 리터럴 대신 토큰(`--white`,
  `--surface-subtle/-muted`, `--track`, `--avatar-soft`, `--code-bg/-fg`)을 사용해
  두 테마가 자동 적응한다. 밝은 배경에서는 잉크 토큰을 진하게 하여 대비를 확보한다.
- **글자 크기(배율)**: `--ui-zoom`으로 전역 배율(기본 1.08 = 한 단계 확대). 상단바
  `가－/가＋`로 sm/md/lg/xl 조절, `localStorage` 저장. `html{zoom}`이라 폰트·여백이 함께
  확대되어 레이아웃이 깨지지 않는다.
- **사이드바**: 밝은 테마. 접기 토글은 세로 중앙의 무테/무배경 화살표로, 사이드바에
  마우스를 올리면 `‹‹`(펼침 시)/`››`(접힘 시)가 나타나며 살짝 미끄러진다.

## 2. 디자인 토큰 (`src/styles/tokens.css`)

- 네이비 계열(`--navy-900/800/700`) — 히어로·강조 텍스트. (사이드바는 밝은 테마: 흰 배경 + 잉크 텍스트, 활성 항목만 브랜드 블루)
- 브랜드 블루(`--brand`, `#1D4ED8`) — 주요 버튼·활성 상태·링크.
- 잉크 그레이(`--ink-900/700/500/400`) — 본문·보조 텍스트.
- 상태색: `--ok`(승인/공개), `--warn`(대기), `--danger`(반려).
- 반경 `--r-sm/r/r-lg`, 그림자 `--shadow-*`, 좌우 여백 `--gutter`.

## 3. 레이아웃

- 좌측 고정 사이드바(236px, 접으면 68px 레일) + 본문. 모든 영역은 `.container`
  하나로 정렬한다.
- 900px 이하에서 사이드바는 오버레이 서랍으로 전환.

## 4. 스타일 파일 구조

- `styles/tokens.css` — CSS 변수(:root).
- `styles/base.css` — 리셋, 공통 컴포넌트(버튼/카드/패널/배지/입력/표/모달/토스트 등).
- 컴포넌트/페이지별 `*.css`는 해당 폴더에 콜로케이션한다.
  (한 페이지 폴더 = `*.tsx` + `*.css`)

## 5. 아이콘 규칙

- 모든 아이콘은 stroke 기반, `currentColor` 상속, 크기 prop으로 제어.
- 신규 아이콘은 `Icon.tsx`에 키를 추가하고, 데이터에서는 키 문자열로 참조한다.

## 6. 접근성·품질

- 버튼/입력에 명확한 포커스 링(`box-shadow`) 유지.
- 색만으로 상태를 구분하지 않고 텍스트 라벨을 함께 제공.
- 한글 가독성을 위해 Pretendard 계열 폰트 스택 사용.
