# DESIGN.md · 프론트엔드 디자인 원칙

## 0. 필수 규칙 — 이모지/이모티콘 사용 금지

- **어떤 화면·컴포넌트·문자열에도 이모지(이모티콘)를 넣지 않는다.** (필수)
- 아이콘이 필요하면 `src/icons/Icon.tsx`의 **인라인 SVG 아이콘 세트**만 사용한다.
- 데이터에도 이모지를 저장하지 않는다. 분류/기능/제공방식의 아이콘은 SVG 키
  (예: `doc`, `auto`, `download`)로 표현한다.
- 코드 리뷰 시 이모지가 발견되면 머지하지 않는다.

## 1. 디자인 출처

시각 디자인은 PoC 원본(`edu_poc_v2.html`)을 그대로 따른다. 색·간격·타이포·컴포넌트
형태를 유지하되, 원본의 이모지 아이콘만 SVG로 대체한다.

## 2. 디자인 토큰 (`src/styles/tokens.css`)

- 네이비 계열(`--navy-900/800/700`) — 사이드바·히어로·강조 텍스트.
- 브랜드 블루(`--brand`, `#1D4ED8`) — 주요 버튼·활성 상태·링크.
- 잉크 그레이(`--ink-900/700/500/400`) — 본문·보조 텍스트.
- 상태색: `--ok`(승인/공개), `--warn`(대기), `--danger`(반려).
- 반경 `--r-sm/r/r-lg`, 그림자 `--shadow-*`, 좌우 여백 `--gutter`.

## 3. 레이아웃

- 좌측 고정 사이드바(236px, 접으면 68px 레일) + 본문. 모든 영역은 `.container`
  하나로 정렬한다.
- 900px 이하에서 사이드바는 오버레이 서랍으로 전환.

## 4. 스타일 파일 구조

- `styles/tokens.css` — CSS 변수(:root).
- `styles/base.css` — 리셋, 공통 컴포넌트(버튼/카드/패널/배지/입력/표/모달/토스트 등).
- 컴포넌트/페이지별 `*.css`는 해당 폴더에 콜로케이션한다.
  (한 페이지 폴더 = `*.tsx` + `*.css`)

## 5. 아이콘 규칙

- 모든 아이콘은 stroke 기반, `currentColor` 상속, 크기 prop으로 제어.
- 신규 아이콘은 `Icon.tsx`에 키를 추가하고, 데이터에서는 키 문자열로 참조한다.

## 6. 접근성·품질

- 버튼/입력에 명확한 포커스 링(`box-shadow`) 유지.
- 색만으로 상태를 구분하지 않고 텍스트 라벨을 함께 제공.
- 한글 가독성을 위해 Pretendard 계열 폰트 스택 사용.
