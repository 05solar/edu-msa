# TEST.md · 프론트엔드 테스트 전략

Phase 1은 목업 기반 데모이므로 수동 스모크 체크리스트를 우선한다. Phase 2에서
단위/통합 테스트(Vitest + Testing Library)를 도입한다.

## 자동 검증

- `npm run typecheck` — 타입 오류 0.
- `npm run build` — 빌드 성공.

## 수동 스모크 체크리스트

### 진입·권한
- [ ] 로그인 화면에서 "데모로 시작하기"로 진입된다.
- [ ] 데모 계정 아이디/비밀번호로도 로그인된다.
- [ ] 좌측 하단 권한 전환으로 일반 사용자/바이브 코더/운영 관리자 전환 시 메뉴가 바뀐다.
- [ ] 일반 사용자에는 "등록"·"운영 관리자" 메뉴가 없다.
- [ ] 실제 계정으로 로그인하면 권한 전환 선택이 보이지 않는다.
- [ ] 새로고침해도 로그인 상태가 유지된다.
- [ ] 로그아웃하면 로그인 화면으로 돌아가고, 새로고침해도 로그인 상태가 아니다.

### 인증 화면
- [ ] 로그인: 아이디를 비우거나 형식이 틀리면 입력칸에 오류가 표시된다.
- [ ] 회원가입: 비밀번호 조건 4개가 입력에 따라 실시간으로 표시된다.
- [ ] 회원가입: 비밀번호 확인이 다르면 오류가 표시된다.
- [ ] 회원가입: 아이디·이메일 형식이 맞아야 "중복 확인" 버튼이 활성화된다.
- [ ] 회원가입: 이미 쓰는 아이디로 중복 확인하면 사용 중이라고 안내한다.
- [ ] 회원가입 성공 후 로그인 화면으로 이동하고, 그 계정으로 로그인된다.
- [ ] 아이디 찾기·비밀번호 찾기: 입력값 검증 후 다음 단계로 넘어간다.
- [ ] 인증번호 영역은 비활성 상태로 "추후 연동" 표시가 보인다.
- [ ] 네 화면 모두 라이트/다크 테마에서 정상으로 보인다.

### 화면
- [ ] 홈: 검색, 업무 분야/기능 유형 바로가기, 인기/최근 목록 표시.
- [ ] 탐색: 업무 분야/기능 유형/기술/공개범위 필터, 정렬, 검색, 결과 카운트.
- [ ] 상세: 소개/사용법/업데이트/의견 탭, 바로 사용하기, 즐겨찾기, 저장소 복사.
- [ ] 등록: 필수값 검증, 태그 입력, 제공 방식 선택, 임시저장/제출.
- [ ] 내 프로그램: 등록 현황(상태 필터), 즐겨찾기, 알림.
- [ ] AI 찾기: 업무 설명 입력 → 추천 결과(데모).
- [ ] 운영 관리자: 검토 대기 승인/반려, 처리 이력, 현황, 카테고리 관리.
